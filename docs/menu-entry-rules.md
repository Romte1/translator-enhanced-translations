# Menu entry rules

These texts are **right-click menu options**, not sentences and not labels.

## Translate the action

Use the action form of the target language, normally the infinitive:

- `Bank` is the action of opening the bank.
- `Empty` and `Empty Dish` are actions: translate the verb, not the adjective or noun.
- `Net` is the action of using a net.
- `View`, `Exit`, `Look-at`, `Deposit`, `Withdraw`, `Check`, `Search`, `Take`,
  `Open`, `Close`, `Use`, `Climb-up` and `Climb-down` are all actions.

Do not translate an action as a noun or an adjective.

## Keep names in English

Never translate item, NPC, boss, place, quest, skill or spell names, even inside a phrase:

- `Buy: 1 x Nature rune` keeps `Nature rune`.
- `View Farming guide` keeps `Farming`.
- `Take Spade` keeps `Spade`.
- `Teleport to Waterbirth Island` keeps `Waterbirth Island`.
- `Cast Ice Blast` keeps `Ice Blast`.

Generic room and interface names can be translated.

## Preserve the format

Copy colour tags, closing tags, numbers, quantities and parentheses exactly. Keep the
English key unchanged; only write the translated value.
